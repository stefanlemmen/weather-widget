Weather Widget design reference

Every state from DESIGN.md, drawn with style.css and sample data for Nieuwegein. Icons animate unless the system asks for reduced motion. Each frame forces one color scheme; the shipped Widget follows the visitor’s.

Full Forecast at three widths

Container queries switch the layout at 20rem and 35rem of the Widget’s own width. The Daily forecast drops its range bar below 24rem, and the Hourly forecast goes to one row of 12 at 45rem.

States

Loading skeleton

Same layout and size as the full Forecast, so nothing moves when it arrives. The bones pulse only without reduced motion.

A failed Forecast part

The Daily forecast failed; Current conditions and the Hourly forecast stay. The heading and band stay too.

Error state

Every requested part failed, or the request itself did. The Location’s name stays.

Fewer Forecast parts

parts="hourly daily": the Hourly forecast moves up under the name with the usual section gap.

Themed through the style attribute

--weather-font: Georgia, serif; --weather-background: #fffaf2; --weather-ink: #2b1d16; --weather-accent: #9c3412; --weather-radius: 0. Every other tone is mixed from these.

Location picker

Idle

A labelled field, a Search button and Use my location. The last one only renders when the Geolocation API exists.

Results

Up to 5 results as buttons, with region and country to tell same-named places apart.

No results

An announced message in place of the list.

Locating

The button is aria-disabled and its arrow pulses (still with reduced motion).

Search failed

The Proxy or the Search provider didn’t answer. The query stays in the field so the visitor can search again.

Location denied

The visitor or the browser blocked location access.

Location timed out

The device didn’t report a position in time.

Location unavailable

The device has no position to give, for example without GPS or network location.

Narrow sidebar

Below 20rem the Search button drops under the field.

Conditions

Eleven Conditions. Day and night variants differ where the sun or moon shows; covered skies and precipitation use one icon.
