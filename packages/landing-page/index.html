Weather Widget

<weather-widget> is a web component that shows the weather forecast for one Location. Each page below embeds one Widget, with a Location picker and Widget settings to change it.

  • Weather Widget in plain HTML

    No framework: loads the Widget as one standalone ES module.

  • Weather Widget in React

    Imports the package and sets the Widget's properties in JSX.

  • Weather Widget in Angular

    Imports the package and binds the Widget's properties in a template.
